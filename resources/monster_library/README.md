# 随附怪物模板库

NewMaple 本地怪物模板查询的默认数据源，直接随项目拉取即可使用，不依赖固定盘符。

## 范围

- 仅从已解包的 `Data/Mob` 与 `BetaData/Mob` 提取 `stand*`、`move*`、`fly*` 数字动作帧，以及对应怪物名称。
- 1,652 个怪物资源记录（Data 1,651；BetaData 1），18,172 个帧引用；SHA-256 去重后 8,262 张 PNG，原图合计 107,591,024 字节（约 103 MiB）。名称缺失时以怪物 ID 显示，不跨数据集借用名称。
- 解析动作及整体怪物引用后写入精简元数据，可脱离原始解包目录使用；每种怪物最多保留查询器支持的 120 帧。
- PNG 原始字节与 Alpha 保留；导入模板时裁掉透明空边，识别时在内存放大 1.5 倍。
- 不包含地图、角色、NPC、装备、音效、攻击/死亡动作、游戏程序、资源目录脚本、完整解包数据库、个人配置、截图或日志。

7 个无可用动作或占位怪物被跳过，具体 ID 见 `manifest.json` 的 `skipped`；不代表客户端所有怪物均有可用识别素材，也不保证被遮挡时能识别。

## 内容

- `catalog.sqlite`：仅有怪物 `files`、`names` 表及名称查询索引。
- `metadata/<dataset>/*.json`：仅含识别动作与库内 PNG 相对路径。
- `images/<哈希前两位>/<SHA-256>.png`：跨怪物去重的原始动作图。
- `manifest.json`：范围、数量、图片字节数及跳过清单。

该目录是查询库，不会将所有怪物自动加入正在使用的识别分类；仍需在“模板采集 → 本地资源库”搜索并选择需要的帧。

## 重新生成

从仓库根目录运行，源目录需包含本项目支持的已解包 `catalog.sqlite`、JSON 和 PNG：

```powershell
.\.venv\Scripts\python.exe tools/build_monster_library.py <已解包资源库目录> <新的输出目录>
```

工具只读源库，拒绝覆盖已有输出目录；只处理 Mob 识别动作和相应名称，不复制原始数据库、完整元数据或资源目录中的程序。重新发布前应核对清单、校验图片并运行测试。
