# 冒险岛弓箭手 — 使用手册

这是给 **经典版 / 怀旧服冒险岛**（窗口标题含 `MapleStory` 或 `冒险岛`，进程多为 `Maplestory_Classic.exe`）用的弓箭手视觉助手。

它只看屏幕像素，再模拟键盘。不读游戏内存、不抓包、不注入。能不能挂机以你所在服的规则为准。

适合：单层横向平台、站着射怪。不适合：爬绳、跳台、自动换图、组队复杂场景。

开发者或用 AI 改代码，请看 [AGENTS.md](AGENTS.md)。

---

## 1. 安装

需要 **Windows** 和 **Python 3.10+**。电脑上如果只有 3.7，直接装依赖会失败。

1. 双击 `Setup.bat`。
2. 若提示下载 Python 3.12，等它装完即可（只装给当前用户，不会替换系统里的旧 Python）。
3. 第一次从别人仓库拉代码时，把 `config.example.json` 复制一份改名为 `config.json`。

之后日常只运行 `Start.bat`，不必反复 Setup。

---

## 2. 启动

先以 **窗口模式** 打开游戏，不要最小化。

| 你要做什么 | 运行什么 |
|---|---|
| 校准、观察、改配置、挂机 | `Start.bat`（或 `Start-Observer.bat`） |
| 直接以管理员打开同一面板并允许发键 | `Start-Bot.bat`（会弹 UAC） |

`Start.bat` 默认是 **观察模式**：会识别、会画框，**不会按技能**。旧的 `Start-Calibrate.bat`、`Capture-*.bat` 仍可用，平时不必再用。

---

## 3. 第一次校准（必须）

打开控制面板后，游戏画面要露出来。按下面顺序点「采集」：

1. **画面校准**  
   依次框选：血条、蓝条、小地图内部、主战斗区；再在小地图上点一下自己的标记。  
   主战斗区请框 **几乎整个可见场景**（可排除底栏和聊天），不要只框脚下一小段平台。
2. **采集怪物模板** 3～6 张  
   工具会 **先冻结当前画面**，请在这张静止图上框一只没被挡住的怪。换动作再采几张。
3. **采集姓名板**  
   同样在静态帧上，紧贴框选自己姓名板第一行蓝底（含名字和两端装饰），不要框到角色、宠物或别人。
4. **采集头部**、**采集称号勋章**  
   各 1～2 张。换发型或换称号后要重采对应那张。
5. **框选攻击范围**  
   角色面向平时攻击的方向，以角色为中心拖一个你想打的范围。框多大，攻击区就多大，助手不会再改成左右对称。

改完攻击键、药键等数字项后，点 **保存配置**。按键也可以点输入框旁的「采集」，然后在游戏画面上按一下真实按键。

---

## 4. 看懂游戏上的框

| 颜色 | 含义 |
|---|---|
| 青色 | 玩家定位（姓名板 / 头部 / 称号） |
| 紫色细框 | 识别到的怪物候选 |
| 绿色粗框 | 当前攻击或接近的目标 |
| 黄色框 | 你框出来的弓箭攻击区，会跟着角色中心和面向移动 |
| 绿色圆点 | 小地图上的自己 |

按 **F7** 可隐藏这些校对框，画面上只留「F7 显示校对信息」；再按一次显示。采集工具打开时 HUD 会整窗收起，互不影响。

确认：青色框在自己身上，黄色攻击区覆盖你想射的距离，怪物走进黄框会变成绿框。

---

## 5. 开始挂机

1. 角色站在目标平台上，面向你要清的方向。
2. 点控制面板 **启动挂机**。若弹出 UAC，选「是」（按键需要和管理员权限的游戏同一级别）。
3. 角色应开始走位、转向、攻击、补药。
4. **暂停**：再点「暂停挂机」或按 **F8**。  
   **退出**：面板「退出程序」、HUD 右上角按钮、**F9** 或 **Ctrl+Shift+Q**。

建议勾选「后台按键」：点面板不会抢走游戏焦点。游戏窗口仍须 **可见、未最小化**；可以放到另一块屏幕，但不要被别的窗口挡住战斗区。

---

## 6. 键位

助手自己的热键不能改：

| 功能 | 键 |
|---|---|
| 显隐校对框 | F7 |
| 启动 / 暂停 | F8 |
| 立即退出 | F9 或 Ctrl+Shift+Q |

游戏内按键在面板「挂机配置」或 `config.json` 的 `keys` 里改。示例默认：攻击 `Shift`，拾取 `Z`，HP `Home`，MP `End`，移动左右方向键。支持字母、数字、Ctrl、Shift、Alt、Home、End、PageUp、PageDown 等。

---

## 7. 常用设置

在面板改完后点 **保存配置**。

- **攻击区前方 / 后方 / 上方 / 下方**：一般用「框选攻击范围」，不必手填。
- **没有目标时左右巡逻**：单层图可开；多层图容易走下平台，默认关。
- **目标丢失后拾取一次**：掉物多再开。
- **HP / MP 阈值**：低于该比例自动喝药。
- **最长运行分钟**：`0` 表示不限时。
- **后台按键**：失焦仍发扫描码；若角色完全不动，把游戏点回前台（有的客户端检查自己是不是前台窗口）。

识别不准时：

- 误把木板、特效当怪 → 提高怪物识别阈值（约 0.75～0.90），或补几张更干净的怪物模板。
- 找不到自己 → 重采姓名板 / 头部 / 称号，保证游戏分辨率没变。
- 改过窗口大小 → 重新画面校准，并重采模板。

---

## 8. 做不到的事

- 不会爬绳、跳层、换图、过门。
- 不识别死亡、断线、背包满、对话框。
- 游戏最小化后无法截图，会停机。
- 不注入、不改内存；无法在「完全切到浏览器且客户端检查前台」时继续控角色。

日志在 `logs` 目录。启动失败时，同目录会有 `crash-*.txt`。
