# 冒险岛弓箭手视觉助手 MVP

这是一个 Windows 纯视觉、固定地图、单层横向平台的弓箭手原型。

它只读取屏幕像素，并通过 Windows `SendInput` 发送普通前台键盘输入；不读取游戏内存、不抓包、不注入游戏进程，也不包含反作弊规避。是否允许自动化由具体服务器规则决定。

## 当前能力

- 按窗口标题找到游戏并只截取客户区。
- 交互式标定血条、蓝条、小地图、战斗区和小地图玩家颜色。
- HSV 检测血蓝剩余量和小地图玩家位置。
- 三路融合定位玩家：优先使用姓名板，遮挡时自动切换到头部或姓名板下方的称号勋章；多路同时可见时互相校验，避免锁定其他玩家。
- 优先选择玩家同层、弓箭有效距离内最近的怪物；射程内没有目标但战斗区仍有同层怪物时，自动走近目标，进入射程后停步攻击。
- 每次射箭前按玩家与目标的实际相对位置重新校正左右朝向。
- 可选：没有目标时，在小地图左右边界之间巡逻；多层地图下默认关闭。
- 低血/低蓝补药、窗口失焦停机、玩家标记丢失停机、最长运行时间限制。
- 状态、血蓝、识别区和怪物框直接以点击穿透 HUD 叠加在游戏画面上；HUD 不会进入视觉截图。
- 默认观察模式；只有 `Start-Bot.bat` 加上 F8 才会发送输入。
- F8 启动/暂停；F9 或 `Ctrl+Shift+Q` 立即退出并释放所有方向键。也可以点击悬浮条右上角的“退出观察/退出程序”。

## 首次使用

1. 运行 `Setup.bat` 安装独立 Python 环境。
2. 以窗口模式打开游戏，保证窗口标题含 `MapleStory` 或 `冒险岛`。
3. 运行 `Start-Calibrate.bat`，依次框选血条、蓝条、小地图内部区域和主战斗区。
4. 在小地图画面中点击自己的玩家标记中心。
5. 找到当前地图一只无遮挡怪物，运行 `Capture-Monster-Template.bat` 框选它。建议保存 3～6 个不同动作帧。
6. 运行 `Capture-Player-Template.bat`，紧贴框选自己姓名板的第一行蓝色板（包含名字和两端装饰），不要包含角色、宠物或怪物。姓名板不随攻击动作和朝向改变，通常采集 1～2 张即可。
7. 分别运行 `Capture-Player-Head-Template.bat` 和 `Capture-Player-Title-Template.bat`，采集自己的头部以及姓名板下方称号勋章。换发型或称号后重新采集对应模板。
8. 运行 `Start-Observer.bat`。确认：青色框落在姓名板、头部或称号上，标签会显示当前定位来源；紫色细框是怪物候选；绿色粗框是最终目标；黄色框是当前弓箭有效索敌区。
9. 关闭观察模式，运行 `Start-Bot.bat`，在 Windows UAC 提示中选择“是”，然后按 F8。再次按 F8 暂停，点击右上角按钮或按 `Ctrl+Shift+Q` 退出。

`Start-Observer.bat` 是纯观察模式，始终不会发送按键，按 F8 也不会启动。需要实际运行时必须关闭观察窗口并改用 `Start-Bot.bat`；按 F8 后程序会自动把游戏切到前台并启动。

当前游戏以高完整性级别运行，因此 `Start-Bot.bat` 会请求管理员权限，使扫描码输入与游戏处于同一权限级别。Observer、校准和模板采集不会提权。

运行、校准和怪物模板采集都直接叠加在游戏主画面上，不再打开独立预览窗口。运行 HUD 点击穿透；校准 HUD 临时接管鼠标用于拖框。HUD 会被排除在视觉截图之外。输入模式只有在游戏保持前台时才会工作。

## 默认键位

| 功能 | 键位 |
|---|---|
| 攻击/技能 | Shift |
| 拾取 | Z |
| HP 药 | Home |
| MP 药 | End |
| 移动 | 左/右方向键 |

在 `config.json` 的 `keys` 中修改。支持字母、数字、方向键、Ctrl、Shift、Alt、Home、End、PageUp、PageDown 等常用键。

## 关键配置

- `vision.monster_template_threshold`：怪物模板阈值。误检时提高，漏检时略微降低；建议保持在 0.75～0.90。
- `vision.monster_detection_scale`：识别缩放比例。默认 0.5，在扩大搜索区域后降低 CPU 占用。
- `vision.monster_hold_seconds`：怪物动画暂时不匹配时保留上次紫框的时间，默认 0.35 秒。
- `vision.player_template_threshold`：玩家姓名板模板阈值，默认 0.70。
- `vision.player_head_threshold` / `player_title_threshold`：头部和称号勋章辅助定位阈值。
- `vision.player_hold_seconds`：三路都短暂丢失时保留上次玩家位置的时间，默认 0.8 秒。
- `behavior.bow_attack_range`：弓箭水平索敌距离，占战斗区宽度的比例，默认 0.312（原值 0.24 的 1.3 倍）。
- `behavior.bow_vertical_tolerance`：玩家与怪物脚底允许的高度差，占战斗区高度的比例，默认 0.12；用于排除其他平台。
- `behavior.patrol_left` / `patrol_right`：小地图中左右折返点，取值 0～1。
- `behavior.hp_threshold` / `mp_threshold`：补药阈值。
- `behavior.fallback_patrol`：没有识别到怪物时是否左右巡逻。多层地图容易走下平台，默认关闭；只在确认当前平台边界后开启。
- `behavior.pickup_after_target_lost`：目标消失后是否按一次拾取，默认关闭。
- `behavior.max_runtime_minutes`：单次最长运行时间；`0` 或负数表示无限制，默认 `0`（无限制）。

## 当前限制

- 只适合单层或近似单层横向平台，不会爬绳、跳台或自动换图。
- 模板匹配依赖相同游戏分辨率和缩放；修改窗口大小后应重新标定、重新截怪物模板。
- 技能特效、伤害数字和怪物动画可能遮挡模板，因此需要多个动作模板。
- 游戏被其他程序遮挡、最小化或失去前台焦点时，输入模式会自动暂停。
- 首版尚未识别死亡、断线、背包满和其他文字弹窗；遇到焦点异常或玩家点丢失会停机。

校准“主战斗区域”时，应框选几乎整个可见游戏场景，而不是只框角色当前所在的一小段平台；可以排除最底部状态栏和聊天框。

运行日志保存在 `logs` 目录，出现异常时会记录启停、攻击和补药事件。
