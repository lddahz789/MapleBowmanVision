# MapleBowmanVision — 使用手册

这是给 **经典版 / 怀旧服冒险岛**（窗口标题含 `MapleStory` 或 `冒险岛`，进程多为 `Maplestory_Classic.exe`）使用的视觉挂机助手，目前包含弓箭手和飞侠·标飞策略。

它只看屏幕像素，再模拟键盘。不读游戏内存、不抓包、不注入。能不能挂机以你所在服的规则为准。

适合：单层横向平台、站着射怪。不适合：爬绳、跳台、自动换图、组队复杂场景。

开发者或用 AI 改代码，请看 [AGENTS.md](AGENTS.md)。

---

## 1. 安装

需要 **Windows** 和 **Python 3.10+**。电脑上如果只有 3.7，直接装依赖会失败。

1. 双击 `Setup.bat`。
2. 若提示下载 Python 3.12，等它装完即可（只装给当前用户，不会替换系统里的旧 Python）。
3. 第一次启动时会自动从 `config.example.json` 创建个人 `config.json`，不会提交或覆盖已有配置。

之后日常只运行 `Start.bat`，不必反复 Setup。

---

## 2. 启动

先以 **窗口模式** 打开游戏，不要最小化。

整个项目只有一个日常启动入口：双击 **`Start.bat`**。启动时会弹出一次 UAC；选择“是”后进入输入待命，但不会自动挂机，也不会发送游戏按键，仍需手动点击“启动挂机”。

---

## 3. 第一次校准（必须）

从 `Start.bat` 启动后，控制台和游戏始终是两个独立窗口。工具是单栏控制面板，不会移动、缩放或停靠游戏；点击采集后，框选层会直接覆盖到游戏原窗口上。每个项目独立采集、独立保存，某项取消或失败不会清空其它项目。
每个采集行的“显示”只会画当前项目；F7 和底部 Debug 开关用于全部显示或全部隐藏。“模板采集”分为“怪物模板”和“人物模板”，玩家姓名板、头部和称号勋章都归在人物模板中。

1. **分别采集血条、蓝条、小地图和小地图玩家标记**
   每行都有“显示”和“采集/重采”。先框小地图内部，再单独点击自己的小地图标记；玩家标记采集时会冻结画面、压暗其它区域并把小地图最高放大 8 倍，点击会映射回原图，只分析点击附近连续、明亮的标记像素。保存前会确认该颜色只命中点击位置，并记录初始位置供启动首帧消歧；姓名板、头部和称号暂时都看不见时，这个实时标记也可用于判断角色是否仍在上次视觉位置。重采小地图后只需重新确认玩家标记。
2. **分别采集战斗识别区域和小地图平台安全点**
   战斗区框选 **几乎整个可见战斗场景**（可排除底栏和聊天）。平台安全点采集会冻结画面并放大小地图，点击目标平台上希望角色返回的中心位置；它只在需要回位的职业策略中作为必要项。重采小地图后需要重新采集玩家标记和平台安全点，重采战斗区不会影响平台安全点。
3. **建立怪物分类，再采集怪物模板** 3～6 张
   在“当前识别分类”中选择或新建分类；助手只会加载并识别当前选中的分类，切换后立即生效，并记住到下次启动。工具会 **先冻结当前画面**，请在这张静止图上框住一只没被挡住的怪，四周可以多留一些背景，程序会分离主体后自动紧裁，换动作再采几张。新模板会保存透明怪物主体；只有完全无法区分怪物与背景时才会提示重新框选。分类和单张模板都可在面板中删除；管理窗口会显示图片预览，连续删除时不会关闭。删除的文件会移入 `assets/template_trash/`。
   如果木板、特效或场景装饰经常被当成当前分类的怪物，选择该分类后点 **采集过滤项**，紧贴框住这个错误目标。过滤项只会排除同分类、同位置的候选。
4. **采集姓名板**
   同样在静态帧上，紧贴框选自己姓名板第一行蓝底（含名字和两端装饰），不要框到角色、宠物或别人；确认模板后继续在同一静态帧点击自己双脚落点中心。
5. **采集头部**、**采集称号勋章**
   各 1～2 张，每张确认后同样点击角色脚底。换发型或换称号后请删除过期模板并重采，避免旧外观匹配到附近玩家。
6. **框选通用索敌范围并选择职业与策略**
   通用索敌区供所有职业策略共享。先选职业，再选该职业的基础策略，并用复选框启用可组合的策略模块；下方会显示对应说明、参数和专属采集项。

改完攻击键、药键等数字项后，点 **保存配置**。按键也可以点输入框旁的「采集」，然后在游戏画面上按一下真实按键。

所有会保存成图片的采集项都可以管理。“怪物模板”中管理怪物与过滤项，“人物模板”中管理姓名板、头部和称号勋章；管理器使用两级分类切换，可预览、新增或删除单张图片。怪物和过滤项使用面板当前选中的怪物分类；删除不会直接销毁文件，而会移入 `assets/template_trash/`，需要时可手动移回原类型目录恢复。删除最后一张姓名板后，必须重新采集姓名板才能启动挂机。

## 4. 看懂游戏上的框

| 颜色 | 含义 |
|---|---|
| 青色 | 玩家定位（姓名板 / 头部 / 称号） |
| 紫色细框 | 识别到的怪物候选 |
| 绿色粗框 | 当前攻击或接近的目标 |
| 黄色框 | 所有职业策略共享的有效索敌区，会跟着角色位置和面向移动 |
| 绿色圆点 | 小地图上的自己 |
| 橙色虚线玩家框 | 小地图标记保持静止时，短时沿用的上次可靠视觉位置 |

面板中的“显示 Debug 框”按钮或 **F7** 控制全部识别框的总显隐；默认显示全部框，各采集项与策略区域旁的“框：开/关”按钮可以独立控制对应框。切换总开关不会清除单项选择。采集工具打开时 HUD 会整窗收起，互不影响。

确认：青色框在自己身上，黄色索敌区覆盖你想射的距离，怪物走进黄框会变成绿框。小地图平台安全点只供策略内部寻路，不在 HUD 上显示。

姓名板候选会在原始分辨率进一步核对本人名字字形；姓名板确认本人后，头部和称号可在预测位置附近连续补位。每次可靠姓名板命中，以及本人身份已由姓名板建立后的连续头部命中，都会固定记录同帧的小地图本人标记。若姓名板和头部随后都未命中、称号也没有提供有效位置，当前唯一标记与这个固定基准相差不超过 2 个小地图像素，助手会在最多 0.2 秒内判断角色仍在原地并短时沿用上次视觉位置；静止帧不会刷新计时。标记移动、缺失、多重命中、尺寸变化或超时会在同一帧清除位置并暂停选敌和攻击，移动后即使回到原点也必须先重新取得视觉命中。程序刚启动且从未由姓名板确认过本人时不会启用这条路径。新采模板使用各自记录的脚底点，旧模板继续兼容固定偏移。

## 5. 开始挂机

1. 角色站在目标平台上，面向你要清的方向。
2. 点击控制面板中的 **启动挂机**。UAC 已在启动 `Start.bat` 时完成，面板不会关闭或重启。
3. 角色应开始走位、转向、攻击、补药。
4. **暂停**：再点「暂停挂机」或按 **F8**。  
   **退出**：面板「退出程序」、HUD 右上角按钮、**F9** 或 **Ctrl+Shift+Q**。

建议勾选「后台按键」：点面板不会抢走游戏焦点。默认同时勾选「挂机时强制游戏窗口置顶」，启动后会置顶游戏，暂停或退出时恢复；如果希望游戏和工具完全独立，可取消该项。取消置顶并使用后台按键时，启动挂机不会抢前台；无论是否置顶，游戏窗口仍须 **可见、未最小化**。

## 6. 键位

助手自己的热键不能改：

| 功能 | 键 |
|---|---|
| 显隐 Debug 框 | F7 |
| 启动 / 暂停 | F8 |
| 立即退出 | F9 或 Ctrl+Shift+Q |

游戏内按键在面板「参数设置」或 `config.json` 的 `keys` 里改。示例默认：攻击 `Shift`，跳跃 `Alt`，拾取 `Z`，HP `Home`，MP `End`，移动左右方向键，下跳方向键为 `Down`。支持字母、数字、Ctrl、Shift、Alt、Home、End、PageUp、PageDown 等。

## 7. 常用设置

挂机配置现在会自动保存：`−/+`、HP/MP 滑杆、复选框和职业策略选择在运行时修改后都会写入 `config.json`；退出程序前还会完整保存一次当前界面值。“保存配置”按钮可用于立即确认并应用全部字段。

- **性能监控**：控制面板顶部每秒刷新实际 / 目标 FPS、整帧平均和 P95 耗时、超预算比例、进程 CPU、内存及截图/识别/决策等分段耗时；CPU 按系统全部逻辑处理器容量归一为 0～100%，与任务管理器口径一致。整帧耗时不包含为了限制 FPS 而主动等待的时间；“决策/输入”会包含跳跃攻击等动作本身的短暂等待。独立喝药模式没有执行的怪物、玩家识别阶段显示 `—`，属于正常现象。点卡片右侧 `×` 可折叠，之后可点“显示性能监控”恢复，状态会自动保存。
- **屏幕三路定位都丢失时，用小地图判断是否仍在原地**：默认开启。当前唯一标记与上次可靠视觉命中时相差不超过 2 个小地图像素，且间隔不超过 0.2 秒时，短时沿用原视觉位置；不会逐帧滚动续命。该开关会自动保存。
- **职业与策略**：先按职业筛选基础策略，再多选该策略的功能模块。“原地攻击”只在当前位置输出；“标飞安全输出”包含可独立开关的近身跳跃攻击和安全区回位。
- **标飞安全输出位置**：安全区默认关闭且不是必要采集项；启用后在放大的小地图上框选，运行时用小地图玩家标记判断位置，不受战斗镜头滚动影响。进入安全区后若没有有效索敌，会在区内左右巡逻并在边界前折返。旧的战斗画面安全区会自动失效，需要重新框选。
- **标飞多索敌区**：每个区域跟随角色位置移动，但保持屏幕方向，不随角色面向左右翻转；旧的屏幕固定区域需要重新框选。
- **姓名板丢失恢复**：超过视觉保持时间仍未识别到姓名板时，会交替左右位移；可调整单向位移秒数或关闭。
- **标飞近身跳跃攻击**：默认开启。怪物与角色的水平重叠达到 20%（可调）时，按 `Alt`，0.05 秒后按 `Shift`，保持 0.05 秒后按相反顺序释放；关闭模块后恢复普通飞镖攻击。
- **索敌区前方 / 后方 / 上方 / 下方**：这是所有职业策略共享的参数，一般用「框选通用索敌范围」，不必手填。
- **怪物轮廓权重**：默认 `0.15`，用于抑制颜色相近但轮廓不同的树干、地形等空气误框；过高可能漏掉动作变化较大的怪物。
- **策略数值微调**：面板为了不抢游戏焦点，使用字段右侧的 `−` / `+` 按钮修改，每次调整 `0.01`；黄色索敌框会实时预览，并立即保存到 `config.json`，重启不会丢失。
- **小地图平台安全半径**：小地图玩家标记超出平台安全点左右这个距离后，“弓箭手动态”会优先回位。数值是小地图内部宽度的比例，例如 `0.12` 表示左右各 12%。
- **没有目标时左右巡逻**：单层图可开；多层图容易走下平台，默认关。
- **目标丢失后拾取一次**：掉物多再开。
- **HP / MP 阈值滑杆**：低于该比例自动喝药；可直接用鼠标拖到 0～100%，也可用两侧按钮每次微调 1%，不需要键盘焦点。
- **独立自动喝药**：这是会话开关，默认关闭。手动开启后，即使没有启动挂机也会继续监测血蓝；非挂机状态只在游戏位于前台时发送药键，并跳过怪物、姓名板等战斗模板识别以降低 CPU 占用。挂机运行中的自动喝药始终按原规则工作，不受该开关影响。
- **最长运行分钟**：`0` 表示不限时。
- **后台按键**：失焦仍发扫描码；若角色完全不动，把游戏点回前台（有的客户端检查自己是不是前台窗口）。
- **挂机时强制游戏窗口置顶**：默认开启，避免普通窗口覆盖识别区；按 F8 暂停、安全停机或退出程序时自动取消置顶。关闭后，后台按键模式不会在启动时抢前台或置顶；前台按键模式仍要求游戏保持前台。

识别不准时：

- 误把木板、特效当怪 → 先删除旧模板并按“主体四周留少量背景”的方式重采；仍有固定误框时在对应怪物分类中采集过滤项，也可提高怪物识别阈值（约 0.75～0.90）或轮廓权重。
- 找不到自己 → 先重采小地图玩家标记；若提示颜色命中多个位置，请点黄色标记最亮的中心。橙色虚线玩家框表示“小地图几乎没动，正在短时沿用上次视觉位置”；如果标记已经移动、持续超过 0.2 秒或仍停机，请重采姓名板 / 头部 / 称号及对应脚底点，并保证游戏分辨率没变。
- 改过窗口大小 → 启动会被阻止；按左侧状态逐项重采。坐标依赖项会自动失效，已有模板图片不会被删除。

协作者新增职业策略时必须遵循 [STRATEGIES.md](STRATEGIES.md)。

## 8. 做不到的事

- 不会爬绳、跳层、换图、过门。
- 不识别死亡、断线、背包满、对话框。
- 游戏最小化后无法截图，会停机。
- 不注入、不改内存；无法在「完全切到浏览器且客户端检查前台」时继续控角色。

日志在 `logs` 目录。启动失败时，同目录会有 `crash-*.txt`。
